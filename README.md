# Japanese Learning - Hiragana N5 🇯🇵

Một ứng dụng web đơn giản giúp người mới bắt đầu học tiếng Nhật ôn tập và ghi nhớ bảng chữ cái Hiragana (trình độ N5). 

Ứng dụng sẽ hiển thị ngẫu nhiên các ký tự Hiragana và yêu cầu người dùng nhập cách đọc (romaji). Hệ thống cung cấp phản hồi trực quan ngay lập tức để tăng hiệu quả học tập.

## Tính năng nổi bật ✨

- **Học tập ngẫu nhiên**: Hiển thị ngẫu nhiên 46 ký tự Hiragana cơ bản.
- **Phản hồi trực quan (Micro-interactions)**:
  - Hiệu ứng phóng to và đổi màu xanh khi nhập đúng.
  - Hiệu ứng rung lắc (shake) và báo lỗi đỏ khi nhập sai.
- **Tính điểm tự động**: Theo dõi tiến độ học tập qua số điểm đạt được.
- **Giao diện hiện đại**: Thiết kế theo phong cách Glassmorphism với màu sắc bắt mắt (vibrant gradients).
- **Tối ưu trải nghiệm**: Tự động focus vào ô nhập liệu, thao tác mượt mà chỉ cần dùng phím Enter.

## Công nghệ sử dụng 🛠️

- **Framework**: [React.js](https://react.dev/)
- **Build Tool**: [Vite 8](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Deploy**: Có thể dễ dàng deploy lên Vercel, Netlify hoặc GitHub Pages.

## Hướng dẫn cài đặt & Chạy cục bộ 🚀

Yêu cầu máy tính của bạn đã cài đặt sẵn [Node.js](https://nodejs.org/) (khuyến nghị phiên bản v20 trở lên).

1. **Clone repository hoặc mở thư mục dự án**:
   ```bash
   cd japanese-learning
   ```

2. **Cài đặt các thư viện cần thiết**:
   ```bash
   npm install
   ```

3. **Khởi động server phát triển (Development Server)**:
   ```bash
   npm run dev
   ```

4. Mở trình duyệt và truy cập vào địa chỉ: `http://localhost:5173`
